# Fix: bench-pi-paired silently produces all-zero results when `pi` command fails

## Root Cause

The benchmark spawns `pi --print --mode json --no-session ...` as a shell command, but `pi` is not installed in this environment. The command exits with status **127** (not found), writing `/bin/sh: 1: pi: not found` to the output file. However:

1. **`runSide()` never checks `run.status`** — it proceeds to parse the error text as Pi JSON output
2. **`parsePiOutput()` silently returns all zeros** when no lines contain valid JSON with Pi event structure
3. **No error or warning is surfaced** — the user sees a table of all-zero results with no indication that the commands failed

## Fix (in `bench/bench-pi-paired.js`)

### 1. Surface command failures in `runSide()` (line ~389)

After the `runCommand()` call, check `run.status`. If non-zero and non-signal, set an `error` field on the result and log a warning:

```js
if (run.status !== 0 && run.status != null) {
  run.error = run.error || `Command exited with status ${run.status}`;
  benchLog(`[bench] WARNING: ${task.id} ${side}: command exited with status ${run.status}`);
}
```

### 2. Detect empty/unparseable output in `parsePiOutput()` (line ~340)

After the parse loop, if no usage was found AND no assistant text was collected AND the raw output is non-empty, return a sentinel indicating the output wasn't valid Pi output:

```js
const isNonEmpty = raw.trim().length > 0;
const hasNoResults = assistantParts.length === 0 && assistantByResponse.size === 0 && seenUsage.size === 0;
if (hasNoResults && isNonEmpty) {
  return {
    usage,
    answer: '',
    tool_counts: {},
    behavior,
    parse_warning: 'No valid Pi events found in output',
  };
}
```

### 3. Fail loudly in `main()` after all tasks run (line ~480)

After the task loop, if **all** tasks have non-zero exit status, print an error and exit with code 1:

```js
const allFailed = results.every((r) => r.memory_off.status !== 0 && r.memory_on.status !== 0);
if (allFailed) {
  benchLog('\n[bench] ERROR: All tasks failed. Are Pi commands available?');
  benchLog('[bench]   Off command: ' + offCommand);
  benchLog('[bench]   On command:  ' + onCommand);
  process.exit(1);
}
```

### 4. Include status/error in per-row output

Add the status to `printRow` output when non-zero, e.g.:

```
task-id  0/3  0/3  ...  off_ms  on_ms  [off:127 on:127]
```

## Files to Change
