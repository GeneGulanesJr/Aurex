### 2. WebSocket Event Replay on Reconnect
- EventBus now maintains a ring buffer history (max 10K events) with sequence numbers
- `getEventsSince(seq)` / `getCurrentSeq()` APIs for replay queries
- WS clients receive a `hello` message with current seq on connect
- Clients send `{ type: "replay", lastSeq }` to catch up on missed events
- `replay_done` acknowledgment sent after replay completes

- REST: Global `onRequest` hook validates `Bearer` token, skips `/health` and `/ws`
- WebSocket: Message-based `{ type: "auth", token }` handshake with 5s timeout
- Added to `.env.example`
