**Files modified:**

- `crosshash-graph/src/lib.rs` — re-export new types

**Dependencies:** `crosshash-graph` needs `crosshash-ai` types, but to avoid circular deps, we'll either:

- (a) Move the shared types (`AiCostEvent`, `AiEdgeSuggestion`, `FeedbackEvent`) into `crosshash-core`, OR

**Decision: Option (b)** — Keep storage methods accepting primitive types (Uuid, String, f64) and do type mapping in the CLI. This avoids adding `crosshash-ai` as a dependency of `crosshash-graph`.

### Step 4: Wire `discover-edges` CLI Command

Replace the stub in `execute_discover_edges()` (`commands.rs:604-653`) with real logic:

1. Load config via `AiConfig`
2. Collect API surfaces from all repos (already done)
3. Run `AiGate::decide()` with real metrics from DB (compare old vs new exports)
4. If gate says run AI:
   - Iterate over repo pairs
   - Call `EdgeInferenceEngine::infer()` for each pair
   - `accept_high_confidence()` → insert auto-accepted as real edges
   - Store pending suggestions via `insert_ai_edge_suggestion()`
   - Record cost via `insert_ai_inference_log()`
5. Print summary: static edges, AI edges suggested, AI cost

For `--dry-run`: print extracted API surfaces without calling LLM (already partially done).
For `--validate`: list pending suggestions from DB.
For `--static-only`: skip AI entirely.

**Files modified:**

- `crosshash-cli/src/commands.rs` — rewrite `execute_discover_edges()` (~80 lines)

**Note:** The CLI is synchronous (`Execute::execute(self) -> Result<()>`) but the LLM client is async. We need `tokio::runtime::Runtime::new().block_on()` to bridge. Check if `main.rs` already uses `#[tokio::main]`.
