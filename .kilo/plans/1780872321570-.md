# Plan: Move Mission Creation to Main Area Inline Form

## Problem
Mission descriptions are typed into a cramped 280px sidebar textarea. This feels clunky for anything beyond a one-liner.

## Solution
Move the mission creation form from the sidebar into the main content area. The sidebar becomes mission-list-only.

---

## Architecture

### Current Flow
```
No mission selected → EmptyState (main) | RepoOverviewPanel (if repo prepared)
Sidebar → NewMissionForm (textarea + repo picker, inline in 280px)
```

### New Flow
```
No mission selected → MissionCreationView (main area, full width)
  ├─ "Create" tab (default): textarea + repo picker + submit + examples
  └─ "Overview" tab (visible only when repo prepared): RepoOverviewPanel content
Sidebar → Mission list only + "New Mission" button (deselects to show creation view)
```

## Edge Cases
1. **User viewing a mission presses `N`**: Deselect current mission → main area shows creation form. Previous mission stays in sidebar list.
2. **User clicks a suggestion in RepoOverviewPanel (Overview tab)**: Switches to the Create tab with the description prefilled.
3. **User clicks example mission card**: Prefills the textarea in the creation form.
4. **Mobile view**: Creation form renders in the main area (full width). Sidebar overlay just shows mission list with no form.
5. **No system ready (integrations not configured)**: Show a warning in the creation form instead of the form fields, similar to current sidebar behavior.
6. **Tab state persistence**: The Create/Overview tab state resets to "Create" when the repo changes or a new repo is prepared.
